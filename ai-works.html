ホーム 手動制作実績 AI協調制作 スキル

AI協調制作（2026年）

一人の人間が4つのAIと分業しながら開発するというスタイルを採用しました。私が全体の設計・方針決定・品質確認を行い、AIが実装・テスト・コードレビューを担当。2ヶ月弱で11以上のサービスを構築し、1,463件の自動テストを整備しました。これは現代のソフトウェア開発における新しい生産性モデルの実践例です。

1,463件 自動テスト
70以上 自動実行タスク
20以上 ダッシュボードページ

A. VPS自動化インフラ全体

Ubuntu VPS (3vCPU/3.8GB RAM) 上に11以上のWebサービスを構築・運用する本番インフラです。Caddyをリバースプロキシとして配置し、Basic認証とHTTPS対応を実現。各サービスはsystemdで管理され、自動再起動やログ管理が設定されています。バックアップはGit管理と暗号化自動バックアップの2層体制で、データの安全性を確保しています。

Ubuntu Caddy systemd Python Node.js SQLite GitHub

B. 運用監視ダッシュボード（20以上のページ）

Git活動の統計、コード複雑度分析、セキュリティ監査、システムリソース監視など、20以上のページで構成される包括的な運用ダッシュボードです。クロン実行履歴、バックアップ状態、LLM API使用量の追跡、稼働率グラフ、ディスク使用量可視化、APIベンチマークなど、VPS運用に必要な情報を一元管理しています。GitHub CopilotによるPR自動作成と連携し、70以上のタスクを自動実行しました。

Python/Flask SQLite Chart.js Playwright (E2E) GitHub Copilot

C. AI自動化パイプライン群

3つの自動化パイプラインを構築しました。

レビュー比較ブログ記事生成パイプライン

8ステージ（judge→intent→outline→draft→smell→check→assemble→route）で構成される記事生成パイプラインです。LLMを活用して製品レビューの比較記事を自動生成し、品質チェックと投稿先ルーティングまでを一貫して処理します。117件のリグレッションテストで品質を担保しています。

Python LLM連携 テスト自動化

バイラルコンテンツ収集パイプライン

SearXNG（ローカルメタ検索エンジン）、はてなブックマーク、X API v2の3つのソースからバイラル候補コンテンツを自動収集します。毎日cronで実行され、収集結果はスコアリングされて投稿候補として管理されます。

Python SearXNG API連携

CG画像集 半自動制作パイプライン

AI画像生成からレビュー、テキスト焼き込み（日本語縦書き対応）、ZIP/PDF出力までを半自動化したパイプラインです。MacBook上のComfyUIとTailscale VPN経由で連携し、E2Eでの制作フローを実証しています。

Python ComfyUI API 画像処理

D. LM Chat / Image Gen Webインターフェース

MacBook上のLM Studio（ローカルLLM）とComfyUI（画像生成）にアクセスするためのWebフロントエンドです。ChatGPTに似たUIでチャットができ、複数セッションの管理、会話のエクスポート/インポートに対応しています。画像生成ではDynamic Prompts構文をサポートし、プロンプトの履歴管理やお気に入り機能を備えています。プライバシーを重視し、サーバー側でのログ保存を無効化する設計です。

Python/Flask JavaScript localStorage

E. Discord Bot「アンシア」

OpenClawフレームワーク上で動作するAIキャラクターbotです。Discordサーバー上で複数のAI（Claude/Gemini/Copilot）の協調作業ハブとして機能し、タスクの受け渡しや進捗報告を仲介します。自律heartbeat機能により、定期的なシステムチェックや作業の自動実行も行います。

Node.js OpenClaw Discord API AI連携

F. Discordログ検索WebUI

Discordの会話ログをSQLite FTS5で全文検索できるWebUIです。チャンネル・著者・日付によるフィルタリング、タイムライン表示、NDJSONフォーマットでのインポートに対応しています。大量のログデータから必要な情報を素早く見つけるために設計しました。

Python/Flask SQLite FTS5 JavaScript

G. ブログサルベージツール

FC2、Livedoor、WordPress、汎用HTMLに対応した記事収集エンジンです。既存ブログの記事をスクレイピングして保存し、プレビューUI上でタグ管理やバルク操作を行えます。Markdownへのエクスポート機能も備え、コンテンツの移行や再利用を容易にしています。

Python/Flask Node.js (Readability) HTML解析

H. プロンプト比較ツール（Prompt Compare）

AI画像生成のプロンプトを並べて比較・評価できるUIツールです。異なるプロンプトによる生成結果の違いを視覚的に確認でき、より良いプロンプトの研究に活用しています。

Python/Flask JavaScript

I. 壊れた画像検出ツール（Broken Image Analyzer）

Webサイト内の壊れた画像リンクを自動検出するツールです。指定したURLをクロールし、404エラーや読み込み不能な画像を一覧表示します。サイトの品質維持に活用しています。

Python

J. テスト・品質保証体制

全システムの品質を支える自動テスト基盤です。Playwrightによる868件のE2Eテストでは、全ページのビジュアル確認、パフォーマンス計測、リンク整合性チェックを実施。ユニットテスト600件以上と合わせて1,463件の自動テストを維持しています。GitHub CopilotによるPR自動レビューも導入し、コード品質の維持を自動化しています。
