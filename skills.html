技術スタック

実務および個人開発で使用している主要な技術です。

server-side

PHP CakePHP2 Python Flask FastAPI Node.js
  • PHP / CakePHP2: Webシステム開発の実務経験（予約システム、ECサイト、業務システム等）
  • Python / Flask: 複数のWebアプリケーション・APIの設計・開発（ダッシュボード、パイプライン等）
  • Python / FastAPI: 非同期APIの開発経験
  • Node.js: IoTデータ受信サーバー、Discord bot開発

frontend

HTML CSS JavaScript jQuery Chart.js Playwright
  • HTML / CSS / JavaScript: レスポンシブWebサイト・WebアプリケーションのUI開発
  • jQuery: 動的UI・Ajax通信の実装（レガシーシステム対応含む）
  • Chart.js: データ可視化ダッシュボードのグラフ・チャート実装
  • Playwright: E2Eテスト868件の設計・実装・保守

infrastructure

Ubuntu Linux VPS Caddy systemd cron Docker Git GitHub
  • Ubuntu Linux / VPS: サーバー構築・運用（11以上のサービスを単一VPSで運用）
  • Caddy: リバースプロキシ設定、Basic認証、TLS自動化
  • systemd: サービスのデーモン化・自動再起動設定
  • cron: 定期タスク自動実行（バックアップ、データ収集、インデックス更新等）
  • Docker: コンテナ環境の構築・GPU対応設定
  • Git / GitHub: バージョン管理、PR運用、Copilot連携

database

SQLite SQLite FTS5 MySQL
  • SQLite: 軽量データベースとして複数プロジェクトで活用
  • SQLite FTS5: 全文検索エンジンの実装（Discordログ検索、インデクサ）
  • MySQL: 業務システムのデータベース設計・運用経験

ai-tools

Claude Code GitHub Copilot Gemini CLI OpenClaw LM Studio ComfyUI Ollama
  • Claude Code / GitHub Copilot / Gemini CLI: AIとの協調開発（設計→実装→テストの全工程で活用）
  • OpenClaw: AI botフレームワーク（Discord bot「アンシア」の基盤）
  • LM Studio: ローカルLLM実行環境の構築・運用
  • ComfyUI: AI画像生成パイプラインの構築（API連携）
  • Ollama: ローカルLLM環境のセットアップ・運用

api-integration

YouTube API Google Maps API Discord API SORACOM SearXNG X API v2
  • YouTube Data API: 動画情報の自動取得・記事生成
  • Google Maps API: 車両位置のリアルタイム可視化
  • Discord API: bot開発・ログ管理
  • SORACOM: IoT機器との通信
  • SearXNG: ローカルメタ検索エンジンの運用
  • X API v2: ソーシャルメディアデータの自動収集
