# 資格試験クイズアプリ

資格試験対策用のブラウザベースクイズアプリです。HTMLファイルをブラウザで開くだけで使えます。

## 特徴

- サーバー不要。HTMLファイルをブラウザで直接開いて利用可能
- 学習履歴をlocalStorageに保存し、間違えた問題を優先的に出題
- 正解数 - 不正解数 が3以上になると「卒業」として出題から除外
- 問題管理UI（追加・編集・削除・JSONインポート/エクスポート）

## 対応資格

### 行政書士

| ファイル | 形式 | 説明 |
|---------|------|------|
| `行政書士/quiz.html` | ○×クイズ | 処分性・原告適格・訴えの利益（基本版） |
| `行政書士/quiz2.html` | ○×クイズ | 加重ランダム出題＋学習履歴付き |
| `行政書士/quiz3.html` | ○×クイズ | 一部問題の復習用 |
| `行政書士/gyosei.html` | 二択クイズ | 行政法・問題管理UI付き |
| `行政書士/kenpo.html` | 二択クイズ | 憲法・問題管理UI付き |
| `行政書士/minpo.html` | 二択クイズ | 民法・問題管理UI付き |

### FP2級

`FP2級/index.html` を開くと科目選択画面が表示されます。

| ファイル | 科目 |
|---------|------|
| `FP2級/life.html` | ライフプランニングと資金計画 |
| `FP2級/risk.html` | リスク管理 |
| `FP2級/kinyu.html` | 金融資産運用 |
| `FP2級/tax.html` | タックスプランニング |
| `FP2級/fudosan.html` | 不動産 |
| `FP2級/souzoku.html` | 相続・事業承継 |

## 使い方

1. 任意のHTMLファイルをブラウザで開く
2. 表示された問題に回答する
3. 学習履歴は自動的にブラウザに保存される

### 問題の追加（二択クイズ）

二択クイズではページ下部の「問題管理」から:
- 問題の追加・編集・削除
- JSONでのインポート/エクスポート
- 学習履歴のリセット

が可能です。
