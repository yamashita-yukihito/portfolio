Project 01

レンタカー予約・管理システム

レンタカー事業者向けの予約・車両管理システムです。バックエンドのほぼ全てとフロントエンドの一部を担当しました。特に力を入れたのはクレジットカード決済機能の実装で、外部決済サービスとのAPI連携を安全に行うための設計に注力しました。顧客情報の取り扱いにはセキュリティを最優先にし、入力バリデーションやCSRF対策を徹底しています。

PHP CakePHP2 jQuery 決済連携
Project 02

会員向けショッピングサイトの改修

既存の会員制ショッピングサイトの機能改修プロジェクトです。ショッピングカートシステムを中心に、新規機能の開発と既存機能の最適化を行いました。カートに商品を追加してから決済完了までのユーザー体験を改善し、離脱率の低減を目指した設計を心がけました。既存コードの理解から始め、影響範囲を慎重に見極めながら改修を進めました。

PHP CakePHP2 jQuery
Project 03

社員向け業務管理システムの改修

社内の業務管理システムにおいて、請求書のPDF出力機能を新規に実装しました。帳票レイアウトの精密な制御が求められる作業で、日本語フォントの埋め込みやページ分割の処理に工夫が必要でした。また、既存機能のバグ修正やメンテナンスも継続的に担当し、安定したシステム運用に貢献しました。

PHP CakePHP2 PDF出力
Project 04

車両リアルタイム位置管理システム

SORACOM SIMを搭載したIoT機器から送信される位置情報をNode.jsサーバーで受信し、Google Maps API上に車両の現在地をリアルタイムで表示するシステムです。IoTデバイスとの通信プロトコルの実装からフロントエンドの地図表示まで、フルスタックで対応しました。データの欠損や遅延に対するエラーハンドリングにも配慮した設計です。

Node.js PHP IoT (SORACOM) Google Maps API
Project 05

RSS自動収集アンテナサイト

VPSの構築からインフラ設定、データベース設計、バックエンド・フロントエンドの実装まで、すべてを一人で担当したプロジェクトです。複数のRSSフィードを自動収集し、カテゴリ分けして表示するアンテナサイトを、自作のPHPフレームワーク上に構築しました。cronによる定期的な自動更新機能も実装し、運用負荷を最小限に抑えています。

PHP 独自FW VPS インフラ構築
Project 06

YouTube API連携 自動投稿ツール

YouTube Data APIを利用して、特定のキーワードに関連する動画を自動検索し、紹介記事を生成・投稿するツールです。APIのレート制限を考慮した効率的なリクエスト設計と、取得データの整形・テンプレート化による記事の自動生成を実現しました。

PHP YouTube API 自動化
Project 07

業務効率化ユーザースクリプト

Tampermonkeyを活用し、既存のWebサービスに対するUI改善スクリプトを自作・運用してきました。日常的に使うサービスの操作性を向上させるための小さなツールですが、DOM操作やイベントハンドリングの実践的な経験を積むことができました。自分の業務を効率化するために技術を使うという、エンジニアとしての基本姿勢が反映されたプロジェクトです。

JavaScript Tampermonkey UI改善
Project 08

ローカルLLM実行環境の構築

WSL2上のUbuntu環境にDockerを導入し、RTX 4070 Ti GPUを活用したローカルLLM実行環境を構築しました。OllamaやOpen WebUIなどのツールを組み合わせ、クラウドに依存せずにLLMを利用できる環境を整備しています。GPU割り当ての最適化やモデルの選定など、ハードウェアリソースを効率的に活用するための調整も行っています。

WSL2 Ubuntu Docker GPU最適化 Ollama
